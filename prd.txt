Buatkan saya aplikasi web Absensi berbasis Artificial Intelligence dengan fitur Face Recognition menggunakan Python sebagai backend dan Firebase Realtime Database sebagai database realtime.

Nama aplikasi:
Absensi-AI

Tujuan aplikasi:
Membuat sistem absensi siswa menggunakan kamera dan teknologi deteksi wajah AI sehingga siswa dapat melakukan absensi otomatis berdasarkan pengenalan wajah.

====================================================
FITUR UTAMA APLIKASI
====================================================

FITUR 1:
ABSENSI WAJAH AI

Alur:

1. Siswa membuka halaman absensi.

2. Browser mengaktifkan kamera.

3. Kamera mengambil frame wajah.

4. Sistem melakukan:
   - face detection
   - face encoding
   - face matching dengan database wajah siswa

5. Jika wajah dikenali:

Simpan data:

{
 id_absensi,
 id_siswa,
 nama_siswa,
 kelas,
 tanggal,
 waktu,
 status:"Hadir",
 confidence_score
}

ke Firebase Realtime Database.


Jika wajah tidak dikenali:
Tampilkan pesan:

"Wajah tidak terdaftar"


Tambahkan:
- confidence percentage
- indikator kamera aktif
- loading ketika proses recognition

====================================================
FACE RECOGNITION SYSTEM
====================================================

Buat modul:

face_recognition_engine.py


Fungsi:

- register_face()
  untuk menyimpan wajah siswa

- encode_face()
  untuk membuat face embedding

- recognize_face()
  untuk mencocokan wajah kamera dengan database


Gunakan:
- OpenCV Camera
- Haar Cascade / CNN detector
- face_recognition library
